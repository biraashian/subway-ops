NOTES:
  The defect: `write_manifest` regenerates CHECKSUMS.txt unconditionally from
  whatever is on disk, and the check then compares disk against that same
  regenerated manifest. So `uv run python -m tools.verify_invariants --update` —
  the documented, blessed command — silently blesses an edit to a migration that

  forgets to run it.
